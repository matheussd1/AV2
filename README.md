# ✈️ Aerocode - Sistema de Gestão Aeroespacial

Este projeto é uma Single Page Application (SPA) desenvolvida em **React**, focada na modernização do fluxo de montagem e controle de qualidade de aeronaves.

## 🛠️ Como rodar o projeto localmente

Siga os passos abaixo para configurar e executar o ambiente em sua máquina:

### 1. Pré-requisitos
* Ter o [Node.js](https://nodejs.org/) instalado.

### 2. Instalação das Dependências
Abra o terminal na pasta raiz do projeto e execute o comando abaixo para instalar as bibliotecas necessárias:
```bash
npm install
npm run dev
